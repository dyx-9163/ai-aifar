模块由两部分组成：`model-runtime/` 是编排与运维脚本层，`models/` 是只读的 Qwen3.5-9B GGUF 权重与多模态投影文件。核心编排定义在 `compose.yaml`，使用 Docker Compose profiles 区分三个服务——`llama-cpu`（纯 CPU）、`llama-hybrid`（CUDA + 部分 GPU layers 混合卸载）、`llama-gpu`（全量 GPU 卸载并启用 Flash Attention、q8_0 K/V cache），均挂载 `../models/*.gguf` 为只读卷并以 `--host 0.0.0.0 --port 8080` 启动 llama.cpp server，对外仅绑定 `127.0.0.1:8080`。PowerShell 脚本提供生命周期管理：`runtime-common.ps1` 集中定义共享函数（Compose 封装、端口占用检测、Docker 守护进程检查、模型工件 SHA-256 校验、健康检查 `/health`、模型发现 `/v1/models`、属性 `/props`、槽位 `/slots` 断言等），`start-model.ps1`、`status-model.ps1`、`stop-model.ps1`、`verify-model.ps1` 作为入口分别调用这些函数；启动时若指定 `gpu` profile 失败且日志中出现 OOM/CUDA 错误，会自动回退到 `hybrid` profile。配置通过 `.env`（或 `.env.example`）注入 `LLAMA_PARALLEL`、`LLAMA_CTX_SIZE`、`LLAMA_N_PREDICT`、`LLAMA_GPU_LAYERS_HYBRID` 等参数。
