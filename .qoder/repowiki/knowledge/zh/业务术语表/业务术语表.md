### 工作区与权限
- 定义：代码 Agent P0.1 阶段的核心交付，指对 AI Agent 可访问的项目根目录、信任等级与网络策略进行显式授权与边界约束，包括路径规范化、穿越防护、排除规则与结构化错误码，是所有后续工具（只读读取、补丁、命令执行）的安全前置条件。
- 别名：workspace sandbox、WorkspaceRecord、trustLevel、networkPolicy

### P0/P1/P2/P3 优先级
- 定义：代码 Agent 路线图中的四个发布优先级，按依赖顺序递进：P0 实现工作区、工具协议、Agent 循环、补丁、命令、验证与任务状态的最低闭环；P1 提升项目级理解与长任务可靠性（AGENTS/Skills、索引、Git 感知、检查点、符号能力）；P2 提升复杂任务覆盖率（浏览器、检索、MCP、并行 Agent、专项审查）；P3 支撑产品化与企业治理（评测、策略、审计、插件治理、性能与发布治理）。每个优先级必须单独形成实施计划、变更范围、安全影响分析与验收记录。
- 别名：优先级定义、交付依赖图、阶段 A/B/C/D

### Tool Runtime
- 定义：Agent Utility Process 之下专门执行已注册工具（Files、Search、Patch、Shell、Git、UI）的隔离层，模型任意输出不得在此执行；所有可变更操作必须产生结构化审计事件，且受 Workspace Sandbox 的根目录、命令、网络与修改范围限制。
- 别名：工具执行层、工具协议

### Utility Process Agent 运行时
- 定义：Electron Utility Process 中承载 Agent 编排循环的 Node.js 环境，负责任务调度、模型调用、上下文构建、工具路由、审批策略、校验器/审查器、检查点管理与 SQLite 持久化，与 Renderer 之间通过类型化 IPC 通信。
- 别名：Agent 运行时、Utility Process

### Provider capability contract
- 定义：客户端根据所选 model profile 声明的能力（reasoning.inputMode、effortOptions、outputModes、concurrency、streaming、usage）而非模型名称猜测来控制功能开关；不支持或未验证的能力保持不可用状态，不会静默丢弃参数伪装成已应用。
- 别名：provider capabilities、模型能力契约

### Turn
- 定义：一次聊天会话中的单次模型请求单元，每个聊天在同一时刻最多只能有一个 queued、running 或 cancelling 的 turn；不同 modelProfileId 拥有独立的队列与容量控制；应用或运行时重启后，持久化的 queued/running/cancelling turn 变为 interrupted，不会自动重放。
- 别名：turn queue、并发槽位、FIFO admission

### Reasoning stream
- 定义：最终答案、原始推理内容与原生推理摘要三者通过 provider 解析、IPC 事件、客户端状态、SQLite 与 UI 渲染各自独立流转；复制/选择答案不包含 reasoning panel 内容，reasoning 有独立的复制动作。流式传输中 direct llama.cpp chunk 保留重复文本与前缀/后缀形状 delta，仅当出现重复显式 SSE id 且数据完全相同时才去重。
- 别名：reasoning output modes、raw reasoning、native summary

### AGENTS.md / SKILL.md
- 定义：代码 Agent 体系中的两类项目级指令文档：AGENTS.md 描述项目约束与工作约定，SKILL.md 描述可复用的专项流程；它们由 Agent 在加载工作区时分层按需加载，属于工程闭环的重要组成部分，但不等同于代码能力本身。
- 别名：项目规则、专项流程、instruction resolver

### Live E2E
- 定义：针对真实本地 Qwen 服务的端到端测试套件，需显式设置 PRIVATE_AI_LIVE_MODEL_E2E=1 并指定 BASE_URL/MODEL_NAME/API_KEY 才会启用；未设置时 suite 在探测前直接跳过。该套件与项目的 fake E2E 服务器相互独立，用于验证实际模型端点的连通性、模型列表匹配与输出边界。
- 别名：live-model.spec、live Qwen suite
