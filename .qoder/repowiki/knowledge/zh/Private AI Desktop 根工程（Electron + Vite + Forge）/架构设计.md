根工程通过 pnpm workspace 聚合 model_runtime（llama.cpp Docker Compose 服务）与 scripts_and_docs（打包校验脚本与文档）两个子模块；Electron Forge 作为统一构建入口，在 forge.config.ts 中为 src/main.ts、src/preload.ts、src/agent/worker.ts 分别绑定 vite.main.config.ts / vite.preload.config.ts / vite.agent.config.ts 独立编译，再通过 vite.renderer.config.ts 产出 main_window 渲染页面，最终经 @electron/asar 打包为 asar 并输出 zip。运行时由主进程启动 Agent Worker 并通过 OpenAI 兼容 HTTP API 调用 model_runtime 暴露的 127.0.0.1:8080 llama.cpp server；scripts_and_docs 中的 verify-package-contents.mjs 在 `pnpm package` 后自动校验产物完整性，形成「构建 → 校验 → 运行」的闭环。
