本模块为纯文档仓库，按主题划分为两个子目录：`docs/code-agent/` 存放 P0–P3 分阶段的代码 Agent 建设路线、验收矩阵与官方参考；`docs/superpowers/` 按 `plans/`（实施计划）、`specs/`（技术规格设计）和 `reports/`（验证报告）三类归档具体特性文档，并以日期前缀命名保证可排序。`.superpowers/sdd/` 用于存放 Superpowers 相关的 SDD 文档。文档之间通过交叉引用形成依赖链：roadmap 作为总纲，各优先级文档定义能力边界与交付物，specs/plans/reports 则围绕同一特性在时间轴上演进。所有文档以 Markdown 为主，部分包含 TypeScript 接口片段、Mermaid 流程图和表格来描述协议、状态机与架构决策。
