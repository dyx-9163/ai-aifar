- 每个 PowerShell 入口脚本采用 `[CmdletBinding()] param(...)` 声明参数，并通过 `if ($MyInvocation.InvocationName -ne '.')` 实现可 source 模式复用。
- 所有脚本统一 `Set-StrictMode -Version Latest` 与 `$ErrorActionPreference = 'Stop'`，并将公共逻辑集中到 `runtime-common.ps1` 后通过 `. (Join-Path $PSScriptRoot 'runtime-common.ps1')` 加载。
- 对 Docker Compose 的调用统一经由 `Invoke-ModelCompose` 函数，固定传入 `-f compose.yaml -p ai-aifar-model --env-file .env(.example)`，避免散落的命令行拼接。
- 对外部状态校验一律使用 `Assert-*` 命名前缀的函数（如 `Assert-ModelArtifacts`、`Assert-ModelPortAvailable`、`Assert-ModelHealthResponse`），失败时直接抛异常。
- 模型工件完整性通过文件名 + 长度 + SHA256 三重校验，期望值硬编码在 `Get-ExpectedModelArtifacts` 中。
- 运行期所有权判定严格限制为单一 `llama-{gpu,hybrid,cpu}` 容器且必须发布到 `127.0.0.1:8080`，防止多个 profile 或外部进程抢占端口。
