- 每个测试用例围绕一个业务场景组织，通过 `afterEach` 或 `finally` 块统一清理临时目录、关闭数据库连接与 Electron 实例，确保测试间隔离。
- E2E 测试使用 `page.getByTestId(...)` 定位 UI 元素，并以 `data-*` 属性（如 `data-runtime-status`、`data-copy-state`、`data-queue-position`）作为稳定断言点。
- 模型后端通过 `startFakeModelServer()` 启动并在 `try/finally` 中调用 `server.close()`，用 `releaseNext`/`failNext` 控制 SSE 响应序列与 HTTP 错误码。
- 工作线程单测通过 `createHarness` 工厂函数构造 `WorkerTurnRuntime`，注入自定义 `streamModel`、`postEvent`、`createTurnId`、`now` 以实现确定性时序与事件捕获。
- 敏感信息（API Key）在失败路径中被断言为未出现在 SQLite、渲染事件与 JSON 快照中，并通过多种编码形式（JSON 转义、URL 编码、大小写混合百分号）验证脱敏覆盖。
- 异步事件就绪通过本地 `eventually` 辅助函数轮询断言，配合 `flushMicrotasks` 推进微任务队列，避免硬编码 sleep。
