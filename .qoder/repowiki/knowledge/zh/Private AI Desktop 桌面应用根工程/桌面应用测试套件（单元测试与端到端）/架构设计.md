测试按运行环境分为两层：顶层 `tests/*.test.ts` 使用 Vitest（`describe/it/expect/vi`）对 Node 侧模块进行单测，包括 worker 轮次调度、模型连接与能力探测、协议序列化、路径安全、流文本归一化、包内容校验等；`tests/e2e/` 使用 Playwright Test（`@playwright/test`）驱动已打包的 Electron 可执行文件（`out/Private AI Desktop-win32-x64/Private AI Desktop.exe`），通过 `launchPackagedApp` 注入 `PRIVATE_AI_DESKTOP_USER_DATA` 隔离用户数据目录，并借助同目录 `fakeModelServer.ts` 启动内存 HTTP SSE 服务器模拟模型后端。E2E 测试通过 `seedWorkspace` 预写 SQLite 数据库（`openDatabase` + `saveModelProfile`/`createThread`）构造会话，再用 Page 对象点击 UI 断言线程队列、并发、取消、红acted 错误等交互行为，并在 finally 中清理临时目录、关闭 Electron 实例和 fake server。单元与 E2E 均通过临时目录 + 内存/SQLite 数据库隔离状态，避免共享副作用。
